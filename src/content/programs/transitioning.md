# Body Recode - Self-Guided Program
## Body State: Transitioning (Score 9–12/15)

---

## What This Program Is

Your scorecard identified your body as currently in a Transitioning state. This means your system is moving out of a high-stress, low-recovery pattern and building capacity to handle progressive training stimulus.

Transitioning state sits between Depleted and Ready. Recovery is improving but not yet stable. Energy is more consistent but not yet reliable. The body can now tolerate progressive loading - but the timing and sequencing of that load still matters.

This 12-week program is built specifically for Transitioning state. The goal is to capitalise on the improving recovery window while building the capacity needed to reach Ready state.

---

## What Transitioning State Means for Your Prescription

| Signal | What it means | What we do |
|---|---|---|
| Improving recovery capacity | Body can handle more than Depleted but still has limits | Moderate volume, structured progression |
| More consistent energy | Output more reliable but still variable | Progressive loading with planned deload |
| Partial stress load reduction | System is stabilising but not fully clear | No maximum intensity work until Phase 2 |
| Better sleep quality | Restoration window improving | Can tolerate slightly higher training density |

**Priority hierarchy for this state:** Recovery and Regulation (RRS) still governs. Training can now progress - but progression blockers must be respected.

---

## Phase Structure - 12 Weeks

| Phase | Weeks | Focus |
|---|---|---|
| Phase 1 - Accumulation | Weeks 1–4 | Build volume baseline, establish movement quality |
| Phase 2 - Intensification | Weeks 5–8 | Increase intensity progressively, reduce volume slightly |
| Phase 3 - Consolidation + Deload | Weeks 9–11 + Week 12 | Consolidate capacity, planned deload in Week 12 |

## Training Protocol

### Frequency
**3–4 sessions per week**

Transitioning state supports 4 sessions for most people. If recovery is variable, stay at 3. Add the 4th session only after Week 4 and only if recovery signals are positive.

### Session Structure

| Block | Type | Purpose |
|---|---|---|
| Warm-up | Movement preparation | 8–10 minutes |
| Block A - Primary | Main compound | Phase-dominant pattern |
| Block B - Secondary | Supporting compound | Reinforces primary |
| Block C - Accessory | Moderate-load accessory | Additional stimulus without competing fatigue |
| Block D - Trunk/Capacity | Trunk stability or conditioning | Resilience work |

### Session Duration
50–65 minutes.

### Volume - Phase 1 (Weeks 1–4)
| Block | Sets |
|---|---|
| Block A | 4 sets |
| Block B | 3–4 sets |
| Block C | 3 sets |
| Block D | 2–3 sets |
| **Total per session** | **12–14 sets** |

### Volume - Phase 2 (Weeks 5–8)
| Block | Sets |
|---|---|
| Block A | 4–5 sets |
| Block B | 3–4 sets |
| Block C | 3 sets |
| Block D | 2 sets |
| **Total per session** | **12–14 sets** |

### Volume - Phase 3 (Weeks 9–11)
| Block | Sets |
|---|---|
| Block A | 4–5 sets |
| Block B | 4 sets |
| Block C | 3–4 sets |
| Block D | 2–3 sets |
| **Total per session** | **13–16 sets** |

### Week 12 - Deload
Reduce all set counts by 40%. Keep same movements, same structure. RPE target drops to 4–5. Full recovery week.

### Intensity

**Phase 1 (Weeks 1–4):**
- Rep range: 8–12 reps
- RPE target: RPE 6–7
- No training to failure

**Phase 2 (Weeks 5–8):**
- Rep range: 6–10 reps (Block A), 8–12 reps (Blocks B–D)
- RPE target: RPE 7–8 (Block A), RPE 6–7 (Blocks B–D)
- One top set per session allowed at RPE 8

**Phase 3 (Weeks 9–11):**
- Rep range: 5–8 reps (Block A), 8–12 reps (Blocks B–D)
- RPE target: RPE 7–8 throughout
- No sets to failure

### Rest Periods
- Block A: 2–3 minutes
- Block B: 90 seconds – 2 minutes
- Block C–D: 60–90 seconds

### Weekly Pattern Structure

**3-day option (Upper / Lower / Full Body)**

**Session 1 - Lower Body**
- Block A: Squat pattern (back squat, front squat, goblet squat)
- Block B: Hinge pattern (RDL, trap bar deadlift)
- Block C: Lunge / split stance
- Block D: Trunk stability

**Session 2 - Upper Body**
- Block A: Horizontal push (bench press, DB press)
- Block B: Horizontal pull (cable row, DB row, barbell row)
- Block C: Vertical pull (lat pulldown, pull-up)
- Block D: Carry or anti-rotation

**Session 3 - Full Body**
- Block A: Squat or hinge variation (lighter)
- Block B: Push or pull variation
- Block C: Accessory lower or upper
- Block D: Trunk / conditioning

**4-day option (Upper / Lower / Upper / Lower)**

Only add the 4th session after Week 4 and only if recovery signals are consistently positive across that week.

**Session 1 - Lower Body (Squat Dominant)**
- Block A: Squat pattern (back squat, goblet squat, leg press)
- Block B: Hinge accessory (RDL, good morning)
- Block C: Lunge / split stance (reverse lunge, split squat)
- Block D: Trunk stability (dead bug, pallof press)

**Session 2 - Upper Body (Push Dominant)**
- Block A: Horizontal push (bench press, DB press)
- Block B: Horizontal pull (cable row, DB row)
- Block C: Vertical push (DB shoulder press, landmine press)
- Block D: Carry or anti-rotation

**Session 3 - Lower Body (Hinge Dominant)**
- Block A: Hinge pattern (trap bar deadlift, conventional deadlift)
- Block B: Squat accessory (leg press, goblet squat - lighter than Session 1)
- Block C: Lunge variation (step-up, walking lunge)
- Block D: Trunk / conditioning (farmer carry, sled push)

**Session 4 - Upper Body (Pull Dominant)**
- Block A: Vertical pull (lat pulldown, assisted pull-up)
- Block B: Horizontal push variation (incline DB press, cable fly)
- Block C: Horizontal pull variation (single arm row, face pull)
- Block D: Bicep / tricep accessory

### Progression Rules
- Progress Block A load when all prescribed sets are completed at or below the target RPE
- Increase load by the smallest available increment
- Do not increase volume and intensity in the same week
- If sleep quality or energy drops across any 3-day window, revert to previous week's load

## Nutrition Protocol


### Principles for Transitioning State

A Transitioning body is beginning to build capacity. Nutrition in this state should support training adaptation without overcorrecting - this is not yet a fat loss phase, but body composition will start to shift naturally as the state improves.

**What that means:**

1. **Slight caloric surplus or maintenance.** Enough to fuel adaptation without excess.
2. **Protein remains the priority.** Supporting new muscle stimulus requires adequate protein.
3. **Time carbohydrates around training.** In Transitioning state, carbohydrate timing begins to matter - around sessions is most effective.
4. **Do not aggressively cut.** The body will begin to recompose naturally as state improves. Cutting while transitioning stalls the process.

### Target Ranges

| Metric | Target |
|---|---|
| Calories | Maintenance to slight surplus. Estimate: bodyweight (kg) x 36-40 kcal. |
| Protein | 1.8-2.2g per kg of bodyweight daily |
| Carbohydrates | Moderate to moderately high. Time the majority around training sessions. |
| Fat | Moderate. Prioritise animal-based sources: beef, eggs, butter, salmon. |
| Meal frequency | 3-4 meals per day |
| Carb timing | 30-60 minutes pre-training and within 60 minutes post-training |

### Priority Foods for Transitioning State

| Priority | Food | Why |
|---|---|---|
| 1 | Beef (grass-fed where possible) | Complete amino acid profile, supports increasing training demands |
| 2 | Eggs (whole) | Highest bioavailable protein, supports tissue repair as volume increases |
| 3 | Salmon / fatty fish | Omega-3 supports recovery as training stress increases |
| 4 | Chicken breast or thighs | Lean protein for meal frequency and volume |
| 5 | Rice, potato, fruit | Quality carbohydrate sources to time around training |
| 6 | Liver (1-2x/week) | Micronutrient support during the adaptation phase |
| 7 | Full-fat dairy (if tolerated) | Protein and caloric density to support slight surplus |

## Sleep and Recovery

**Target:** 7–8.5 hours per night.

By Transitioning state, sleep is improving. Protect it - the recovery gains you are making now are driven largely by what happens outside the gym.

**Week 12 Deload:** The planned deload in Week 12 is not optional. It is the mechanism that allows Phase 3 gains to consolidate. Do not replace the deload with additional training.

---

## What to Expect

**Weeks 1–4:** Sessions feel manageable. Volume is higher than a Depleted program but still moderate. Energy should feel more consistent by Week 3.

**Weeks 5–8:** Intensity increases. Performance in Block A should improve measurably. Sleep quality and energy consistency should be notably better.

**Weeks 9–11:** Consolidation. The body is approaching Ready state. Performance plateau is normal here - do not force more volume.

**Week 12:** Deload. Do it. Trust the process.

**At the end of 12 weeks:** A new scorecard will tell you whether you have moved into Ready state. Most Transitioning clients hit Ready state or high Transitioning by the end of this program.

## Glossary

**RPE (Rate of Perceived Exertion)**
A scale from 1–10 that measures how hard a set feels. RPE 5 means you could do 5 more reps. RPE 7 means you could do 3 more. RPE 8 means you could do 2 more. RPE 10 is absolute maximum effort. This program uses RPE to guide load selection rather than prescribing a specific weight - because the right weight is different for every person and changes week to week.

**Sets**
A group of repetitions performed without stopping. "3 sets of 10" means you perform 10 reps, rest, then repeat that twice more.

**Reps (Repetitions)**
The number of times you perform a movement within one set.

**Rep Range**
A target window for reps per set (e.g. 8–12 reps). Choose a weight that makes the last rep of the range feel like the target RPE. If 12 reps feels too easy, increase the weight. If 8 reps feels too hard, reduce it.

**Compound Movement**
An exercise that works multiple muscle groups and joints at the same time. Examples: squat, deadlift, bench press, row. These are the primary training stimulus in each session.

**Accessory Movement**
A lower-priority exercise that supports the compound work without adding significant fatigue. Examples: bicep curl, lateral raise, leg curl.

**Trunk Stability**
Exercises that train the muscles that support and protect the spine - without loading the spine directly. Examples: plank, dead bug, pallof press, farmer carry. Not the same as "ab work."

**Axial Load**
Load that travels vertically through the spine. Exercises like back squats and overhead press carry high axial load. This program manages axial load progressively as state improves.

**Deload**
A planned week of reduced training volume and intensity. Not a rest week - you still train. The purpose is to allow the accumulated fatigue from previous weeks to dissipate so the body can consolidate the gains made. Skipping a deload does not produce better results. It produces worse ones.

**Upper / Lower Split**
A training structure where some sessions focus on the upper body and others on the lower body. In a 3–4 day structure, this allows higher frequency per muscle group than a traditional body part split.

**Progressive Overload**
The principle of gradually increasing the demand placed on the body over time. This is what drives adaptation. In this program, overload is applied through small load increases once performance and recovery targets are met - not by training harder regardless of readiness.

**Phase**
A distinct training block with a specific focus. Each phase in this program has a different volume, intensity, and intent. Moving through phases in order is important - skipping ahead does not accelerate results.

**Body State**
The classification your scorecard assigned you - Depleted, Transitioning, or Ready. It reflects how your body is currently handling stress, recovering from training, and managing energy output. It is not a permanent label. It changes as the conditions driving it change.
