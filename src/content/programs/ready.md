## What This Program Is

Your scorecard identified your body as currently in a Ready state. This means your system has sufficient recovery capacity, stable energy output, and the ability to handle and adapt to progressive training stress.

Ready state is where real performance and body composition change happens. The body is no longer spending its resources on stabilisation - it is available for adaptation.

This 12-week program is built to capitalise on Ready state. Volume and intensity are both elevated relative to the other states, and progression is structured to drive meaningful change within the 12-week window.

---

## What Ready State Means for Your Prescription

| Signal | What it means | What we do |
|---|---|---|
| High recovery capacity | Body can handle and adapt to training stress | Higher volume and intensity are appropriate |
| Consistent energy | Output is reliable session to session | Can use intensity-dependent methods (RPE 7–8+) |
| Low stress load | Systemic resources available for adaptation | Progressive overload is safe and productive |
| Strong sleep quality | Restoration window fully functional | Training density can increase |

**Priority hierarchy for this state:** RRS still governs - if recovery signals deteriorate at any point, reduce load immediately. Ready state is not permanent. Protect it.

## Phase Structure - 12 Weeks

| Phase | Weeks | Focus |
|---|---|---|
| Phase 1 - Accumulation | Weeks 1–4 | Build volume base, establish working weights |
| Phase 2 - Intensification | Weeks 5–8 | Increase intensity, reduce volume slightly, drive adaptation |
| Phase 3 - Realisation + Deload | Weeks 9–11 + Week 12 | Express capacity, planned deload Week 12 |

## Training Protocol

### Frequency
**4 sessions per week**

Ready state supports 4 sessions with adequate recovery. A 5th session can be added in Phase 2–3 for locomotion/capacity work only - no additional compound loading.

### Session Structure

| Block | Type | Purpose |
|---|---|---|
| Warm-up | Movement preparation | 8–10 minutes |
| Block A - Primary | Main compound | High intensity, phase-dominant |
| Block B - Secondary | Secondary compound | Reinforces primary, moderate intensity |
| Block C - Accessory | Moderate-load accessory | Volume accumulation |
| Block D - Trunk/Capacity | Trunk stability or conditioning | Resilience |

### Session Duration
55–70 minutes.

### Volume - Phase 1 (Weeks 1–4)
| Block | Sets |
|---|---|
| Block A | 4–5 sets |
| Block B | 4 sets |
| Block C | 3–4 sets |
| Block D | 2–3 sets |
| **Total per session** | **13–16 sets** |

### Volume - Phase 2 (Weeks 5–8)
| Block | Sets |
|---|---|
| Block A | 4–5 sets |
| Block B | 3–4 sets |
| Block C | 3 sets |
| Block D | 2–3 sets |
| **Total per session** | **12–15 sets** |

### Volume - Phase 3 (Weeks 9–11)
| Block | Sets |
|---|---|
| Block A | 4–5 sets |
| Block B | 4 sets |
| Block C | 3 sets |
| Block D | 2 sets |
| **Total per session** | **13–14 sets** |

### Week 12 - Deload
Reduce all set counts by 40–50%. Same movements, same structure. RPE target drops to 4–5. Full recovery week before reassessment.

### Intensity

**Phase 1 (Weeks 1–4):**
- Rep range: 6–10 reps (Block A), 8–12 reps (Blocks B–D)
- RPE target: RPE 6–7 (Block A), RPE 6 (Blocks B–D)
- Establish baseline working weights - do not push RPE ceiling

**Phase 2 (Weeks 5–8):**
- Rep range: 4–8 reps (Block A), 6–10 reps (Block B), 8–12 reps (Blocks C–D)
- RPE target: RPE 7–8 (Block A), RPE 7 (Block B), RPE 6–7 (Blocks C–D)
- One top set per session at RPE 8–8.5 permitted

**Phase 3 (Weeks 9–11):**
- Rep range: 3–6 reps (Block A), 6–8 reps (Block B), 8–12 reps (Blocks C–D)
- RPE target: RPE 8–8.5 (Block A), RPE 7–8 (Block B), RPE 6–7 (Blocks C–D)
- No training to failure - controlled expression only

### Rest Periods
- Block A: 2.5–4 minutes (longer in Phase 3)
- Block B: 2–2.5 minutes
- Block C: 60–90 seconds
- Block D: 60 seconds

### Weekly Split - Upper / Lower / Upper / Lower

**Session 1 - Lower Body (Squat Dominant)**
- Block A: Squat pattern (back squat, front squat)
- Block B: Hinge accessory (RDL, good morning)
- Block C: Lunge or split stance (Bulgarian split squat, walking lunge)
- Block D: Trunk stability (ab wheel, pallof press, dead bug)

**Session 2 - Upper Body (Push Dominant)**
- Block A: Horizontal push (barbell bench press, DB press)
- Block B: Horizontal pull (barbell row, cable row)
- Block C: Vertical push (DB shoulder press, landmine press)
- Block D: Carry or anti-rotation

**Session 3 - Lower Body (Hinge Dominant)**
- Block A: Hinge (conventional deadlift, trap bar deadlift)
- Block B: Squat accessory (leg press, goblet squat)
- Block C: Lunge variation
- Block D: Trunk / conditioning (farmer carry, sled push)

**Session 4 - Upper Body (Pull Dominant)**
- Block A: Vertical pull (weighted pull-up, lat pulldown)
- Block B: Horizontal push variation (incline DB press, cable fly)
- Block C: Horizontal pull variation (single arm row, face pull)
- Block D: Bicep / tricep accessory


### Progression Rules
- Progress Block A when all prescribed sets completed at or below target RPE
- Increase by smallest available increment only
- Do not increase volume and intensity in the same week
- If performance drops across two consecutive sessions, hold load - do not progress
- If energy or sleep degrades across a 3-day window, reduce Block A sets by 1 and reassess

## Nutrition Protocol


### Principles for Ready State

A Ready body is in an optimal position for body recomposition. This is where fat loss and muscle building can happen simultaneously - but only if the nutrition supports the training stimulus.

**What that means:**

1. **Slight caloric deficit or maintenance for fat loss / slight surplus for muscle gain.** Define the goal before setting the target.
2. **Protein is non-negotiable.** Higher training volume requires more substrate for repair.
3. **Carbohydrate timing matters here more than in other states.** Pre and intra-training fuel drives performance. Post-training carbohydrates drive recovery.
4. **Do not undereat.** Aggressive deficits in Ready state will pull the body back toward Transitioning or Depleted. The goal is to stay in Ready while recomposing.

### Target Ranges

| Metric | Target |
|---|---|
| Calories | Goal dependent. Fat loss: bodyweight (kg) x 30-32 kcal. Muscle gain: bodyweight (kg) x 38-42 kcal. Recomp: bodyweight (kg) x 34-36 kcal. |
| Protein | 2.0-2.4g per kg of bodyweight daily |
| Carbohydrates | Moderate to high. Timing is critical at this state. |
| Fat | Moderate. Do not drop below 0.8g per kg bodyweight. |
| Meal frequency | 4 meals per day aligned with training schedule |
| Pre-training nutrition | 30-60 minutes before: 30-50g carbohydrates, 20-30g protein |
| Post-training nutrition | Within 60 minutes after: 40-60g carbohydrates, 30-40g protein |

### Priority Foods for Ready State

| Priority | Food | Why |
|---|---|---|
| 1 | Beef (grass-fed where possible) | Complete amino acid profile, supports high training volume |
| 2 | Eggs (whole) | Highest bioavailable protein, supports daily protein targets |
| 3 | Salmon / fatty fish (2-3x/week) | Omega-3 supports recovery at higher training intensities |
| 4 | Chicken breast | Lean protein source, easy to hit daily targets |
| 5 | Rice, potato, fruit | Primary carbohydrate sources for pre and post-training windows |
| 6 | Liver (1x/week) | Micronutrient density to support high training output |
| 7 | Greek yoghurt / cottage cheese | Casein protein supports overnight recovery |

## Sleep and Recovery

**Target:** 7–8 hours per night.

In Ready state, sleep is your performance lever. The higher the training intensity, the more critical sleep quality becomes.

**Week 12 Deload:** Non-negotiable. Realization gains are consolidated during the deload, not during training. Skipping it leaves performance on the table.

---

## What to Expect

**Weeks 1–4:** Working weights are conservative by design. The point is to establish a clean baseline. Performance improvement starts in Week 3.

**Weeks 5–8:** This is where the adaptation happens. Block A intensity increases. Performance should improve measurably week over week.

**Weeks 9–11:** Realisation phase. Expressing what has been built. Do not add volume here - the gains are already in the system.

**Week 12:** Deload. Hard stop.

**At the end of 12 weeks:** A new scorecard will confirm whether you have maintained or improved your Ready state. Most clients who complete this program at full effort maintain Ready state and are ready to enter a coaching program with strong baseline data.

## Glossary

**RPE (Rate of Perceived Exertion)**
A scale from 1–10 that measures how hard a set feels. RPE 5 means you could do 5 more reps. RPE 7 means you could do 3 more. RPE 8 means you could do 2 more. RPE 10 is absolute maximum effort. This program uses RPE to guide load selection rather than prescribing a specific weight - because the right weight is different for every person and changes week to week.

**Sets**
A group of repetitions performed without stopping. "3 sets of 10" means you perform 10 reps, rest, then repeat that twice more.

**Reps (Repetitions)**
The number of times you perform a movement within one set.

**Rep Range**
A target window for reps per set (e.g. 8–12 reps). Choose a weight that makes the last rep of the range feel like the target RPE. If 12 reps feels too easy, increase the weight. If 8 reps feels too hard, reduce it.

**Compound Movement**
An exercise that works multiple muscle groups and joints at the same time. Examples: squat, deadlift, bench press, row. These are the primary training stimulus in each session.

**Accessory Movement**
A lower-priority exercise that supports the compound work without adding significant fatigue. Examples: bicep curl, lateral raise, leg curl.

**Trunk Stability**
Exercises that train the muscles that support and protect the spine - without loading the spine directly. Examples: plank, dead bug, pallof press, farmer carry. Not the same as "ab work."

**Axial Load**
Load that travels vertically through the spine. Exercises like back squats and overhead press carry high axial load. Ready state programs manage axial load carefully even at higher intensities.

**Deload**
A planned week of reduced training volume and intensity. Not a rest week - you still train. The purpose is to allow the accumulated fatigue from previous weeks to dissipate so the body can consolidate the gains made. Skipping a deload does not produce better results. It produces worse ones.

**Upper / Lower Split**
A training structure where sessions alternate between upper body focus and lower body focus. In a 4-day structure, each area is trained twice per week - increasing stimulus frequency without requiring more total sessions.

**Progressive Overload**
The principle of gradually increasing the demand placed on the body over time. This is what drives adaptation. In this program, overload is applied through small load increases once performance and recovery targets are met - not by training harder regardless of readiness.

**Top Set**
A single set performed at the highest intensity for that session - typically RPE 8–8.5. All other sets for that exercise are performed at a lower intensity to accumulate volume without exceeding recovery capacity.

**Phase**
A distinct training block with a specific focus. Each phase in this program has a different volume, intensity, and intent. Moving through phases in order is important - skipping ahead does not accelerate results.

**Body State**
The classification your scorecard assigned you - Depleted, Transitioning, or Ready. It reflects how your body is currently handling stress, recovering from training, and managing energy output. It is not a permanent label. It changes as the conditions driving it change.

**Body Recomposition**
Simultaneously reducing body fat and building muscle. This is only achievable when the body is in Ready state and nutrition is precisely calibrated. It does not happen in Depleted state, and only partially in Transitioning state.
