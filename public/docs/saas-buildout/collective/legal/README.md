## Why two documents

The commercial agreement and the IP licence are separated so the licence deed can survive independently of the commercial contract if needed (for enforcement, litigation, or renegotiation). This is standard practice for software + IP-heavy commercial relationships.

Both documents cross-reference each other and must be signed together as one package.

## How to use these drafts

1. **Read the cover note first.** It flags the sections that need a lawyer's eye most.
2. **Review the agreement + licence in parallel.** Definitions are shared across both.
3. **Mark up in Word.** Import via pandoc to a `.docx` copy (see `_pdf_build` folder for reference).
4. **Return with a redlined v0.2** for Kade to review before final v1.0 execution.
